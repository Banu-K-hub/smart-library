# 📚 Smart Library — жасанды интеллектке негізделген ақылды кітапхана

**Smart Library** — колледж бен ЖОО кітапханасына арналған ЖИ-көмекші.
Оқырман кітапты атауымен ғана емес, **мағынасы бойынша** еркін сөзбен іздей алады
(қазақ және орыс тілдерінде), жеке ұсыныстар алады, ЖИ-кеңесшіге сұрақ қояды және кітапты онлайн брондайды.

> «AI autumn» конкурсы · Бағыты: Табиғи тілді өңдеу (NLP) және LLM

## Мүмкіндіктері
| Модуль | Сипаттамасы |
|---|---|
| 🔎 Мағыналық іздеу | TF-IDF (символдық n-грамдар) + LaBSE нейрондық моделі (гибридті іздеу) |
| 💬 ЖИ-кеңесші | Сұрау тілін және ниетін анықтайды: кітап іздеу, бар-жоғын тексеру, кітапхана ережелері |
| ⭐ Ұсыныстар | Оқу тарихы мен таңдаулылар негізіндегі контенттік ұсыныс жүйесі |
| 📚 Менің кітаптарым | Брондау, алу, қайтару, мерзімді ұзарту, мерзім туралы ескертулер |
| 📊 Статистика | Кітапханашыға арналған көрсеткіштер |
| 🌐 Екі тіл | Интерфейс қазақ және орыс тілдерінде |

## Іске қосу
```bash
# 1. Python 3.10+ қажет
python -m venv .venv
# Windows: .venv\Scripts\activate    Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt

# 2. Қосымшаны іске қосу
streamlit run app.py
```
Браузерде `http://localhost:8501` ашылады.

**Нейрондық іздеу (міндетті емес, бірақ ұсынылады):**
```bash
pip install sentence-transformers
```
Алғашқы іске қосуда LaBSE моделі (~1,8 ГБ) интернеттен жүктеледі. Модель жоқ болса,
қосымша автоматты түрде TF-IDF режимінде жұмыс істей береді. Ағымдағы режим сол жақ панельде көрсетіледі.
Нейрондық модельді өшіру: `SMART_LIBRARY_NEURAL=0`.

**LLM (міндетті емес):** `.env.example` файлын `.env` деп көшіріп, `OPENAI_API_KEY` енгізсеңіз,
кеңесші табылған кітаптар негізінде LLM арқылы жауап береді. Кілт кодта сақталмайды.

## Сапаны тексеру
```bash
python evaluate.py
```
Іздеудің Top-1, Top-3, MRR көрсеткіштерін (қазақша/орысша бөлек) және кеңесшінің сұрау түрін анықтау дәлдігін шығарады.

## Жоба құрылымы
```
smart_library/
├── app.py                 # Streamlit веб-интерфейсі
├── evaluate.py            # Сапаны бағалау
├── core/
│   ├── search.py          # Гибридті мағыналық іздеу + ұсыныс жүйесі
│   ├── assistant.py       # ЖИ-кеңесші (intent + RAG)
│   ├── db.py              # SQLite: оқырмандар, брондар, таңдаулылар
│   ├── text.py            # Мәтінді өңдеу, тілді анықтау
│   └── i18n.py            # Интерфейс мәтіндері (kk/ru)
├── data/
│   ├── books.json         # Каталог (47 кітап, аннотациялар kk/ru)
│   └── faq.json           # Кітапхана ережелері
└── tests/test_queries.json
```
